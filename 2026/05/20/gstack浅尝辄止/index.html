技能清单

THINK 阶段（6 个）

技能 核心作用
office-hours YC 式需求验证，6 个强迫性问题揭示需求真相
plan-ceo-review CEO 视角范围审查（扩大/保持/缩小）
plan-eng-review 工程经理视角技术审查（架构/数据流/边界）
plan-design-review 设计师视角 0-10 评分 + 交互式修复
design-consultation 从零构建完整设计系统（DESIGN.md）
autoplan CEO → 设计 → 工程 三连自动审查管线

BUILD 阶段（1 个）

技能 核心作用
investigate 系统化根因调试，四阶段 + freeze hooks 编辑隔离

REVIEW 阶段（3 个）

技能 核心作用
review 预合并 PR 审查（SQL 安全 / LLM 信任边界 / 条件副作用）
design-review 设计师视角 QA（视觉一致性 + AI slop 检测 + 自动修复）
codex OpenAI Codex 跨模型第二意见

TEST 阶段（6 个）

技能 核心作用
browse Playwright 无头浏览器（截图/表单/响应式/对比）
setup-browser-cookies 从真实浏览器导入 Cookie
qa 完整 QA 测试-修复-验证循环（三级深度）
qa-only 只报告不修复的 QA 模式
benchmark Core Web Vitals 性能回归检测
cso 首席安全官（OWASP Top 10 + STRIDE 威胁建模）

SHIP 阶段（5 个）

技能 核心作用
ship 全流程交付（测试 → 审查 → 版本号 → CHANGELOG → PR）
land-and-deploy 合并 PR + CI + 部署 + 生产验证
canary 部署后监控循环（错误/性能/页面健康）
setup-deploy 一次性部署配置（自动检测平台）
document-release 交付后文档同步

REFLECT 阶段（1 个）

技能 核心作用
retro 周工程回顾（人均贡献/发布连续性/测试健康趋势）

Power Tools（6 个）

技能 核心作用

guard careful + freeze 组合安全模式

对比

gstack适合需要完整工程团队视角的项目，特别是创业者和产品负责人。其23个专业角色覆盖了从产品构思到部署上线的全流程，是”一个人即一个团队”理念的最佳实践。

everything-claude-code是资源最丰富的综合解决方案，200+ Skills和跨平台支持使其成为多平台团队的首选。适合需要快速找到特定领域工具的场景，也是探索AI编程工具生态的最佳入口。

superpowers提供了最清晰的工程化方法论，强制TDD和系统化审查流程使其成为追求代码质量团队的首选。14个核心技能虽少但精，覆盖了软件开发的本质流程。

可根据项目阶段组合使用：

方案一：渐进式增强

•初期：superpowers（建立工程化习惯）

•中期：gstack（引入专业角色分工）

•后期：everything-claude-code（扩展特定领域技能）

方案二：场景化切换

•产品设计阶段：gstack的CEO/设计师角色

•开发实施阶段：superpowers的TDD流程

•特定任务处理：ECC的专项Skills

小结

从 everything-claude-code 的”全能”，到 Superpowers 的”纪律”，再到 gstack 的”团队”——三款工具代表了 AI 编程的三个演进方向：

  • 入门探索 → 用 ECC，打开视野

  • 习惯养成 → 用 Superpowers，建立工程思维

  • 团队作战 → 用 gstack，实现一人成军

工具只是放大器，判断力和产品 sense 才是核心。
