一、核心简介（精简版）

gstack 是AI全流程开发工作流，依托Claude Code搭建虚拟研发团队，一站式完成需求梳理→架构设计→编码→审代码→测试→发布→复盘，单人效率比肩团队，MIT开源免费，适配主流AI编程工具。

核心效率数据
2026有效逻辑代码产出 = 2013年同期240倍，日均效率提升810倍

二、30秒极简安装

  1. 依赖：Claude Code、Git、Bun1.0+
  2. 终端执行安装
  3. 团队协同（强制启用）

三、最快上手6步

  1. /office-hours 梳理真实需求
  2. /plan-ceo-review 产品战略评审
  3. /plan-eng-review 技术架构评审
  4. /review 代码审核
  5. /qa 线上真机测试
  6. /ship 一键打包发布

四、全常用指令中英对照（高频必用）

斜杠指令 中文释义 适用场景
/office-hours 需求深度问诊 项目立项、梳理核心痛点
/plan-ceo-review 创始人战略评审 敲定产品方向、取舍功能
/plan-eng-review 技术架构评审 定数据流、接口、容错方案
/plan-design-review UI设计评审 审核页面布局、视觉交互
/review 代码正式审核 查隐藏BUG、冗余代码
/qa 全流程真机测试 站点联调、业务流程测通
/qa-only 仅出具测试报告 只查bug，不修改代码
/design-shotgun 多方案UI样机生成 批量出设计效果图选型
/design-html 设计稿转生产代码 样机一键转可上线前端
/autoplan 全自动一站式规划 懒人全流程自动出方案
/investigate 根源问题排查 线上故障、疑难bug定位
/cso 全方位安全审计 合规检测、漏洞扫描
/ship 合并代码+提交PR 开发完成提合并请求
/land-and-deploy 合并上线部署 正式合并分支、发布生产
/canary 线上灰度监控 上线后监控报错、性能
/benchmark 页面性能跑分 测速、优化网页性能
/document-release 同步更新项目文档 自动更新README/架构文档
/retro 项目开发复盘 每周工作总结、效率优化
/browse 模拟真人浏览器操作 网页自动化操作、登录测试
/setup-browser-cookies 导入本地浏览器Cookie 登录态页面免登录测试
/pair-agent 多AI智能体协同 多个AI共用浏览器协作
/codex 跨模型二次代码复审 Claude+OpenAI双重审代码
/careful 高危操作安全提醒 防止删库、强制推送等误操作
/freeze 锁定代码编辑目录 调试时只改指定文件夹
/guard 双重安全防护 同时开启提醒+目录锁定
/unfreeze 解除目录锁定 恢复全目录编辑权限
/gstack-upgrade 一键升级gstack 更新至最新工作流版本
/learn 沉淀项目开发经验 留存项目习惯、避坑要点
/setup-gbrain 搭建AI持久化知识库 让AI长期记住项目逻辑
/sync-gbrain 同步代码至知识库 更新项目代码记忆库
